Change Tracking for Document Templates

Built a change tracking system for a document automation platform. The feature introduced real-time visibility into template modifications: dedicated side panel shows list of changes in chronological order. Users can review individual changes via a modal. The goal was to improve transparency and safety when editing complex, structured legal content—where small text changes can have significant downstream effects in generated contracts.
