Document automation app

Change Tracking for Document Templates

Built a change tracking system for a document automation platform. The feature introduced real-time visibility into document modifications: dedicated side panel shows list of changes in chronological order. Users can review individual changes via a modal.
The goal was to improve changes history when editing complex legal documents.

Autofill Fields - Driven by Datasource

Implemented a datasource system that dynamically populates questionnaire fields based on dropdown selections. Each selected option can carry additional data or trigger API requests to retrieve extended information, which is then used to automatically fill related fields.

Context-Aware Paragraph Creation

Built a feature that adds more paragraphs based on existing content. The output can be refined by "regenerate" feature, allowing for extra prompt.

AI Question Generation from Document Content

Implemented automatic generation of questionnaire items based on existing headings and paragraph content.

AI Paragraph Generation

Added AI-powered paragraph creation, aware of its master heading and surrounding text.
